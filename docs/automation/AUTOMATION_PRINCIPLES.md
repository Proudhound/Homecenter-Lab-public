# Automation principles

1. Observe before automating.
2. Prefer deterministic rules for critical functions.
3. Preserve manual operation.
4. Start with high-value, low-risk routines.
5. Document failure behavior.
6. Avoid hidden dependencies on a developer workstation or cloud service.
7. Keep family-facing controls simple.

## Typical first automations
- morning overview
- appliance-finished notification
- good-night status summary
- energy-use suggestion
- work/do-not-disturb status indicator
