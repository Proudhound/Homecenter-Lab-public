# Security and publication policy

This public repository is a sanitized mirror of selected material from a private home-lab repository.

## Never publish
- passwords, API keys, tokens or recovery secrets
- private/public VPN key material or credential QR codes
- IP addresses tied to the real home network
- MAC addresses
- serial numbers or unique device IDs
- private hostnames or internal DNS names
- exact physical placement of security devices
- camera footage or snapshots
- personally identifiable household information
- exported Home Assistant secrets or credentials

## Public-safe examples
Use documentation-only placeholders such as `192.0.2.10`, `2001:db8::/32`, `SERVER-01`, `HA-VM` and `NAS-01`.

## Reporting
If you notice information that could expose private infrastructure or personal data, please open an issue without repeating the sensitive value in full.
