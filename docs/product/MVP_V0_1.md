# HomeCenter MVP – Release 0.1

## Goal
Validate that a local-first Home Assistant platform can combine family information and selected home systems in a way that reduces app switching and enables useful automation.

## Must include
- stable Home Assistant base
- separate family/admin views
- secrets outside version control
- documented backup concept
- family board with date, calendar, weather, countdowns, shopping access and compact home status
- integration pilots for network infrastructure, energy/storage and a connected household appliance
- at least three reliable everyday automations or assists

## Not part of 0.1
- complete heating overhaul
- full-house sensor deployment
- LLM-controlled critical automation
- large hardware purchases without a defined use case
- full second-brain stack
