# Family Value Gate

Before adding hardware, integrations or automation, ask:

1. Does this solve a real recurring problem?
2. Who benefits from it?
3. Is the benefit understandable without technical knowledge?
4. Can the same value be achieved with existing hardware?
5. Does it create a new single point of failure?
6. Can the underlying home function still be operated manually?
7. Does it improve reliability, safety, time, energy use or convenience enough to justify the complexity?

If the value is mostly technical curiosity, the item belongs in the experiment backlog rather than the family-critical path.
