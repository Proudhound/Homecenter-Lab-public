# Support

[Deutsch](#deutsch) · [English](#english)

## Deutsch

HomeCenter Lab Public ist ein öffentlich dokumentiertes Community-/Open-Source-Projekt und kein kommerzieller Helpdesk.

Support wird nach Möglichkeit und ohne garantierte Reaktionszeit geleistet.

### Wobei wir helfen

GitHub Issues können genutzt werden für:

- Fehler in veröffentlichten Anleitungen
- reproduzierbare Probleme mit Beispielen aus diesem Repository
- Verständnisfragen zu unserer veröffentlichten Dokumentation
- fehlerhafte oder veraltete Links
- Probleme, die wahrscheinlich direkt durch veröffentlichte HomeCenter-Konfigurationen oder Konzepte verursacht werden
- Vorschläge zur Verbesserung der Dokumentation

Bitte beschreibe das Problem so, dass es ohne Zugriff auf dein privates Netzwerk nachvollziehbar ist.

### Was kein Projekt-Support ist

Dieses Repository ist nicht der richtige Ort für allgemeine individuelle Fehleranalyse zu:

- beliebigen Home-Assistant-Installationen
- fremden Proxmox-Systemen
- allgemeinen Heimnetzproblemen
- herstellerspezifischem Produktsupport
- individuellen Kaufberatungen ohne direkten Projektbezug
- vollständiger Einrichtung eines privaten Home-Labs
- professioneller IT-, Security- oder Netzwerkberatung

Für solche Fragen sind die offiziellen Dokumentationen und jeweiligen Fachcommunities in der Regel die bessere Anlaufstelle.

### Gute Support-Anfrage

Bitte gib – soweit relevant und sicher veröffentlichbar – an:

- welches Dokument oder Beispiel betroffen ist
- erwartetes Verhalten
- tatsächliches Verhalten
- relevante Software-/Hardwareversion
- bereits durchgeführte Schritte
- reproduzierbare Fehlermeldung
- minimal notwendige, anonymisierte Konfiguration

Veröffentliche **keine Secrets oder privaten Infrastrukturdetails**, nur um eine Support-Anfrage vollständiger erscheinen zu lassen.

### Sicherheit und Datenschutz

Bitte poste niemals:

- Passwörter
- API-Keys oder Tokens
- VPN-/SSH-Schlüssel
- Recovery-Secrets
- reale private Netzwerkpläne mit unnötigen Identifikatoren
- MAC-Adressen
- Seriennummern
- personenbezogene Daten
- private Kameraaufnahmen
- Informationen, die physische Sicherheitsmaßnahmen unnötig offenlegen

Wenn ein Problem eine mögliche Sicherheitslücke oder versehentlich veröffentlichte sensible Information betrifft, beachte [SECURITY.md](SECURITY.md) und wiederhole sensible Daten nicht öffentlich.

### Antwortzeiten

Es gibt **keine garantierten Antwort- oder Lösungszeiten**.

HomeCenter Lab Public wird neben anderen Verpflichtungen betrieben. Issues können beantwortet, priorisiert, zusammengeführt, geschlossen oder auf externe Dokumentation verwiesen werden.

### Hersteller- und Drittanbieterprodukte

HomeCenter Lab ist nicht mit den in der Dokumentation genannten Herstellern verbunden, sofern dies nicht ausdrücklich angegeben wird.

Fragen zu Garantie, Defekten, Accounts, Abonnements oder herstellerspezifischen Diensten sollten direkt an den jeweiligen Anbieter gerichtet werden.

### Professionelle oder kommerzielle Unterstützung

Derzeit wird über dieses Repository **keine kommerzielle Beratung oder bezahlte Supportleistung angeboten**.

Sollte sich das ändern, wird dies transparent dokumentiert.

### Das Projekt unterstützen

Diese Datei beschreibt, **wie man Hilfe zum Projekt erhält**.

Finanzielle Unterstützung, Hardwarebereitstellungen, Sponsoring, Partnerschaften und Transparenzregeln werden getrennt dokumentiert. Dadurch bleiben technischer Support und wirtschaftliche Beziehungen klar voneinander getrennt.

## English

HomeCenter Lab Public is a publicly documented community/open-source project, not a commercial help desk.

Support is provided on a best-effort basis with no guaranteed response time.

### What we support

GitHub Issues may be used for:

- errors in published guides
- reproducible problems with examples from this repository
- questions about the published HomeCenter documentation
- broken or outdated links
- problems likely caused directly by published HomeCenter configurations or concepts
- documentation improvement proposals

Please describe the problem so that it can be understood without access to your private network.

### What is outside project support

This repository is not intended for general troubleshooting of arbitrary Home Assistant or Proxmox installations, unrelated home-network problems, vendor product support, unrelated purchasing advice, complete setup of private home labs or professional IT/security/network consulting.

Official documentation and the relevant specialist communities are generally better places for those requests.

### A useful support request

Where relevant and safe to publish, include:

- affected document or example
- expected behavior
- actual behavior
- relevant software/hardware version
- troubleshooting already performed
- reproducible error message
- minimal anonymized configuration

Never publish secrets or private infrastructure information simply to make a support request appear more complete.

### Security and privacy

Do not post passwords, API keys, tokens, VPN/SSH keys, recovery secrets, unnecessary real network identifiers, MAC addresses, serial numbers, personal information, private camera footage or details that unnecessarily expose physical security measures.

For potential security issues or accidentally published sensitive information, follow [SECURITY.md](SECURITY.md) and do not repeat the sensitive information publicly.

### Response times

There are **no guaranteed response or resolution times**. Issues may be answered, prioritized, merged, closed or redirected to external documentation.

### Vendors and third-party products

HomeCenter Lab is not affiliated with vendors mentioned in the documentation unless explicitly stated otherwise. Warranty, account, subscription and vendor-service questions should be directed to the relevant provider.

### Professional or commercial support

No commercial consulting or paid support service is currently offered through this repository.

### Supporting the project

This file explains **how to get help with the project**.

Financial support, hardware contributions, sponsorships, partnerships and transparency rules will be documented separately so technical support and commercial relationships remain clearly separated.
