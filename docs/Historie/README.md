# Historie

Dieser Bereich dokumentiert öffentlich verwertbare Inbetriebnahmen, Umbauten, Migrationen und Fehleranalysen des HomeCenter Labs.

Die Einträge sollen nicht nur das Endergebnis zeigen, sondern auch:

- Ausgangslage und Ziel,
- tatsächlich ausgeführte Schritte,
- beobachtete Probleme,
- Diagnoseweg und Lösung,
- offene Punkte und nächste Schritte.

## Publication Security Gate

Historieneinträge stammen teilweise aus dem privaten HomeCenter-Betriebsjournal. Vor der Veröffentlichung werden sie aktiv sanitisiert.

Nicht übernommen werden insbesondere:

- Seriennummern und eindeutige Gerätekennungen,
- MAC- und private IP-Adressen,
- interne Hostnamen,
- Lizenz-/Produktschlüssel,
- Tokens, Recovery-Secrets und Zugangsdaten,
- private Standort- oder Haushaltsdetails.

Der technische Lernwert soll erhalten bleiben, ohne die reale private Infrastruktur offenzulegen.
