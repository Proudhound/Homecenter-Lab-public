# HomeCenter Lab Public

**HomeCenter Lab Public** is the public documentation and open-source layer of my private home lab.

The project documents the development of a practical, local-first home infrastructure for family life, smart home, automation, self-hosting, energy, backups and local AI.

## Principles
- Family first
- Local first
- Integrate before replace
- Manual control must survive
- Security by publication design
- Reproducible where possible

## Scope
- Home Assistant and family dashboards
- Proxmox and home-server architecture
- Networking concepts
- Backups and operations
- Smart-home automation
- Energy integration
- Local AI and voice services
- Public-safe hardware documentation

## Publication policy

This repository does **not** contain IP addresses, MAC addresses, device serial numbers, private hostnames, Wi-Fi/VPN credentials, API keys, secrets, camera footage or personal household details.

## Status

Active build phase. Public-safe material is mirrored here from the private HomeCenter repository in sanitized form.
